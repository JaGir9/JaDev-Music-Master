# Roadmap

## Phase 1 — Production foundation

- professional Qt desktop shell
- project / track model
- FFmpeg/FFprobe integration
- source inspection
- converter profiles
- structured configuration
- logs and error handling
- Windows packaging

## Phase 2 — Analysis and QC

- EBU R128 loudness analysis
- true peak
- clipping / silence / DC checks
- spectral descriptors
- stereo correlation
- BPM and key
- report view

## Phase 3 — Adaptive mastering

- deterministic adaptive EQ
- dynamics policy
- transient policy
- saturation policy
- stereo guard
- limiter and loudness targets
- before/after metrics
- rollback / strength reduction guard

## Phase 4 — Local tagging

- offline genre/style tagging
- confidence display
- genre as advisory input to processing
- manual override
- no cloud API requirement

## Phase 5 — Merge / Mix workstation

- reorderable timeline
- gapless and crossfade render
- loudness matching
- chapter/cue output
- optional BPM/key-aware transitions

## Phase 6 — UX polish

- waveform
- spectrum analyzer
- LUFS and true-peak meters
- theme selector
- icon, logo, splash screen
- installer and portable build
- update documentation

## Phase 7 — Validation

- regression test corpus
- blind A/B listening workflows
- genre-diverse test material
- performance benchmarking
- export compatibility testing
